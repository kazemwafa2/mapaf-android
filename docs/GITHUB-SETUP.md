# راهنمای میزبانی بسته آفلاین نقشه روی گیت‌هاب

این راهنما برای آن است که فایل داده نقشه افغانستان (۱۳۶ مگابایت `af.pmtiles`) و مجموعه داده‌ها
را روی گیت‌هاب بگذارید تا برنامه **نقشه افغانستان** در حالت آفلاین از همان‌جا دانلود و نصب کند.

## چرا Release؟

گیت‌هاب برای فایل‌های معمولی مخزن حد ۱۰۰ مگابایت دارد؛ فایل نقشه ۱۳۶ مگابایت است.
**GitHub Releases** برای فایل‌های بزرگ تا ۲ گیگابایت است و دانلود آن سریع و بدون محدودیت عملی است.

## گام ۱ — ساخت مخزن

در حساب گیت‌هاب خود یک مخزن جدید بسازید، مثلاً:

```
mapaf-offline-data
```

(میتواند Private هم باشد، اما برای دانلود در برنامه بهتر است Public باشد.)

## گام ۲ — ساخت Release و بارگذاری فایل‌ها

1. در صفحه مخزن: **Releases → Create a new release**
2. در قسمت Tag، مقدار `v1.0` را بنویسید (انتخاب «New tag»)
3. عنوان مثلاً «بسته آفلاین نقشه افغانستان — نسخه ۱.۰»
4. این فایل‌ها را از پوشه `offline-data/` به بخش «Attach binaries» بکشید:

   - `MANIFEST.json`
   - `af.pmtiles`  ← فایل اصلی نقشه (۱۳۶ MB)
   - `provinces.geojson`
   - `postal_codes.json`
   - `places.json`
   - `summary.json`

5. **Publish release** را بزنید.

## گام ۳ — نشانی پایه بسته را در برنامه بدهید

نشانی پایه بسته این می‌شود:

```
https://github.com/USERNAME/mapaf-offline-data/releases/download/v1.0
```

(به‌جای `USERNAME` نام کاربری گیت‌هاب خود را بگذارید.)

در برنامه: **تنظیمات → نشانی بسته آفلاین در گیت‌هاب** → همین نشانی را وارد و ذخیره کنید.

سپس در **مدیریت بسته آفلاین → بررسی نسخه جدید → دانلود و نصب بسته**.
برنامه خودش `MANIFEST.json` را می‌خواند، همه فایل‌ها را دانلود می‌کند، **SHA-256** هر فایل را
تأیید می‌کند و نقشه آفلاین را فعال می‌سازد. بعد از آن حتی با قطع اینترنت نقشه کامل کار می‌کند.

## گام ۴ — بروزرسانی‌ها (اختیاری)

هر وقت داده تازه‌ای خواستید بگذارید:

1. Release جدید با تگ `v1.1` بسازید و فایل‌های تازه را همان‌جا بارگذاری کنید
2. در برنامه نشانی جدید (با `v1.1`) را در تنظیمات وارد کنید و بسته را نصب کنید

## فایل‌های داده — از کجا آمده‌اند؟

| فایل | منبع |
|---|---|
| `af.pmtiles` | کپی رسمی نقشه پایه map.af (`tiles.map.af/basemap/af.pmtiles`) — قالب PMTiles/OpenMapTiles از داده OpenStreetMap (ODbL) با snapshot ‏۲۰۲۶-۰۸-۰۶ |
| `provinces.geojson` | مرز رسمی ۳۴ ولایت — geoBoundaries gbOpen AFG ADM1 (CC BY 4.0) + نام‌های دری/پشتو و مراکز ولایتی |
| `postal_codes.json` | ۶۹۹ کد پستی شش‌رقمی پست افغانستان با مختصات — از صفحات عمومی `map.af/postcodes` |
| `places.json` | ۳۲,۵۷۴ مکان مسکونی افغانستان — GeoNames (CC BY 4.0؛ یکی از منابع اعلامی map.af) |
| `summary.json` | آمار رسمی صفحه «درباره ما» map.af |
| `MANIFEST.json` | فهرست فایل‌ها + اندازه + SHA-256 + نسخه — برنامه برای نصب مطمئن از آن استفاده می‌کند |

## استفاده مجدد از اسکریپت‌ها

در پوشه `scripts/` همه اسکریپت‌های ساختن داده هست:

- `scrape_postcodes.py` — دوباره گرفتن کدهای پستی از map.af
- `build_datasets.py` — بازسازی provinces.geojson، places.json، summary.json
- `gen_manifest.py` — بازسازی MANIFEST.json (بعد از هر تغییر داده اجرا شود)
- `gen_voice.py` — تولید دوباره فایل‌های صوتی
- `test_pmtiles_logic.py` — آزمودن خواننده PMTiles در برابر کتابخانه رسمی
