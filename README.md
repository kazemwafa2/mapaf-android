# نقشه افغانستان — نسخه اندروید بر پایه map.af + الگوی بلد

برنامه اندروید نقشه و مسیریاب برای افغانستان که **داده و نقشه از map.af** گرفته می‌شود و
**ساختار ویژگی‌ها، راهنمای صوتی و صداهای داخل برنامه** بر الگوی برنامه «بلد» ساخته شده است.

---

> **معماری مستقل (نسخه ۱.۱):** برنامه به **هیچ API از map.af وابسته نیست**. همه داده‌ها (نقشه، جستجو، مسیریابی) از فایل‌های خود سایت استخراج و داخل برنامه/بسته گیت‌هاب قرار گرفته است. مسیریابی با موتور A* روی‌دستگاه انجام می‌شود.

## ۱. چه چیزی از کجا گرفته شده؟

| بخش | منبع | توضیح |
|---|---|---|
| نقشه پایه (کامل کشور، زوم ۰ تا ۱۴، ساختمان‌ها، سرک‌ها، POIها) | `https://tiles.map.af/basemap/af.pmtiles` | فایل PMTiles به حجم **۱۳۶ مگابایت** — دقیقاً همان فایلی که وب‌سایت map.af اجرا می‌کند |
| سبک نقشه (رنگ‌ها، فونت‌ها، اسپرایت‌ها) | `map.af/static/styles/light.json` و `dark.json` | داخل برنامه قرار دارد (`assets/style_light.json`، `style_dark.json`) |
| جستجوی آنلاین | `https://map.af/api/search?q=…` | با توکن عمومی `GET /api/token` (مدت اعتبار ۶۰۰ ثانیه) |
| آدرس‌یابی نقطه | `GET /api/address/at?lat=..&lng=..` | |
| مسیریابی | **موتور داخلی A\*** روی گراف راه‌ها استخراج‌شده از `af.pmtiles` (لایه transportation در زوم ۱۳) | ۳٫۴ میلیون گره؛ دوخته‌شده در مرز تایل‌ها؛ کاملاً آفلاین و مستقل — بدون هیچ API |
| کدهای پستی | `https://map.af/postcodes` | **۶۹۹ کد شش‌رقمی پست افغانستان با مختصات** از ۳۴ ولایت استخراج و داخل برنامه گذاشته شد |
| مکان‌های آفلاین | GeoNames (یکی از منابع اعلامی خود map.af) | **۳۲,۵۷۴ مکان** با نام دری/انگلیسی برای جستجوی آفلاین |
| مرز ۳۴ ولایت | geoBoundaries gbOpen AFG ADM1 (CC BY 4.0) | `provinces.geojson` |
| آب و هوا | MET Norway Locationforecast 2.0 | همان منبع اعلام‌شده در صفحه «درباره ما» map.af |
| آمار رسمی | صفحه «درباره ما» map.af | ۹,۸۸۴,۰۰۰ ساختمان · ۷,۵۸۲,۰۰۰ دارای آدرس · ۱۲۹,۷۳۶ جای ثبت‌شده · ۵۷,۳۱۷ سرک نام‌گذاری‌شده · ۱,۴۰۸ کد پستی · ۳۴ ولایت — در صفحه «درباره map.af» برنامه نمایش داده می‌شود |

راهنمای صوتی (فایل‌های MP3 دری/پشتو/انگلیسی) و صداهای هشدار (زنگ پیچ، رسیدن، بازمحاسبه مسیر)
**داخل خود برنامه** ساخته و قرار داده شده و به هیچ سایتی وابسته نیست.

## ۲. ویژگی‌های برنامه

- **نقشه کامل افغانستان** با موتور MapLibre (همان موتور وب map.af) — سه‌بعدی ساختمان‌ها در زوم بالا
- **دو حالت:**
  - **آنلاین:** تایل‌ها مستقیماً از `tiles.map.af/basemap/af.pmtiles` با درخواست‌های HTTP Range جریان می‌شود (بدون نیاز به سرور واسط)
  - **آفلاین:** بسته نصب‌شده از **گیت‌هاب** دانلود و روی گوشی ذخیره می‌شود و برنامه از همان فایل محلی می‌خواند
- **جستجوی کاملاً آفلاین:** پایگاه ۸۶,۰۰۰+ ردیف (مکان‌های ثبت‌شده map.af از صفحات عمومی + همه خیابان‌ها/POIهای نقشه + GeoNames) + کدهای پستی — بدون هیچ API
- **مسیریابی صوتی (Turn-by-Turn):** دستورهای «پنجاه متری… صد متری… چپ/راست بپیچید…»، «مسیر دوباره محاسبه شد»، «به مقصد رسیدید» — سه زبان، با تشخیص خروج از مسیر و حالت آزمایشی (شبیه‌سازی) برای تست بدون GPS
- **کدهای پستی:** مرور بر اساس ولایت + جستجو + باز شدن روی نقشه
- **ولایات:** فهرست ۳۴ ولایت با مرکز، کد و شمار کدهای پستی
- **آب و هوا** از MET Norway
- **درباره map.af:** آمار رسمی + اسناد منابع داده
- زبان‌ها: **دری / پښتو / English** — پشتیبانی کامل RTL

## ۴. ساختن APK

### راه اول — Android Studio (پیشنهادی)
1. پوشه `mapaf-android` را در Android Studio باز کنید (File → Open)
2. صبر کنید تا Gradle همگام شود
3. `Build → Build Bundle(s)/APK(s) → Build APK(s)`

### راه دوم — خط فرمان
```bash
cd mapaf-android
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

### راه سوم — بدون نصب هیچ‌چیز: GitHub Actions
پروژه را به گیت‌هاب پوش کنید؛ workflow فایل `.github/workflows/build-apk.yml` خودش APK می‌سازد
و در بخش **Actions → Artifacts** برای دانلود قرار می‌دهد.

## ۵. نصب بسته آفلاین روی گیت‌هاب (گام‌به‌گام)

پوشه `download/offline-data/` را ببینید؛ محتوای آن باید روی گیت‌هاب برود:

| فایل | حجم | توضیح |
|---|---|---|
| `af.pmtiles` | ۱۳۶ MB | کل نقشه کشور (بیشتر از حد مجاز فایل معمولی گیت‌هاب=۱۰۰MB است → **باید Release asset شود**) |
| `MANIFEST.json` | ~1 KB | نسخه، فهرست فایل‌ها، SHA-256 هر فایل |
| `provinces.geojson` | ۱۷۸ KB | مرز ۳۴ ولایت |
| `postal_codes.json` | ۱۵۱ KB | ۶۹۹ کد پستی با مختصات |
| `places.json` | ۵ MB | ۳۲,۵۷۴ مکان برای جستجوی آفلاین |
| `summary.json` | ~2 KB | آمار رسمی map.af |

**گام‌ها:**
1. در گیت‌هاب یک مخزن بسازید، مثلاً `mapaf-offline-data`
2. به **Releases → Draft a new release** بروید، تگ `v1.0` بسازید
3. هر شش فایل بالا را به عنوان **release asset** بارگذاری کنید (Release محدودیت حجم عملی ندارد و دانلود آن سریع است)
4. نشانی پایه بسته این می‌شود:
   `https://github.com/USERNAME/mapaf-offline-data/releases/download/v1.0`
5. در برنامه: تنظیمات → «نشانی بسته آفلاین در گیت‌هاب» → همین نشانی را بگذارید و ذخیره کنید
6. در «مدیریت بسته آفلاین» → **بررسی نسخه جدید** → **دانلود و نصب بسته** — برنامه MANIFEST را می‌خواند، همه فایل‌ها را دانلود، SHA-256 را تأیید و نقشه آفلاین را فعال می‌کند

برای بروزرسانی: فایل‌های تازه را در Release جدید (مثلاً `v1.1`) بگذارید و همان نشانی جدید را در برنامه وارد کنید.

> یادداشت: جریان آنلاین برنامه نیازی به گیت‌هاب ندارد و مستقیماً از سرور map.af می‌خواند؛
> گیت‌هاب فقط برای **حالت آفلاین** است.

## ۷. محدودیت‌های شناخته‌شده

1. **مکان‌های ثبت‌شده:** map.af همه ۱۲۹,۷۳۶ جای ثبت‌شده را در صفحات عمومی با فرمت JSON-LD منتشر می‌کند. در زمان ساخت این نسخه، ~۲,۰۰۰ مورد (به دلیل محدودیت نرخ سرور) برداشت شد و در جستجو هست؛ اسکریپت `scripts/scrape_places.py` قابل ازسرگیری است و با اجرای ~۱٫۵ روز (یا روی GitHub Actions) کل ۱۲۹,۷۳۶ مورد جمع و با `build_search_db.py` + `gen_manifest.py` بسته به‌روز می‌شود.
2. **کدهای پستی:** map.af در صفحه خود عدد ۱,۴۰۸ را اعلام می‌کند؛ در صفحات عمومی ولایات ۶۹۹ کد با مختصات منتشر شده که همان‌ها داخل برنامه است.
3. **مسیریابی:** موتور داخلی است و محدودیت‌های یک‌طرفه بودن برخی معابر (دیتای تایل) و شتاب کلاس‌بندی‌شده تقریبی را دارد؛ برای مسیریابی شهری و بین‌شهری روی شبکه اصلی دقیق است.
